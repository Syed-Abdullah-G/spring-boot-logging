
# Spring Boot Logging

A Spring Boot project demonstrating logging with **SLF4J** and **Logback**, including log levels, console output, and file-based logging.

## Tech Stack

- Java
- Spring Boot
- SLF4J
- Logback
- Maven

## Features

- Configure logging using `application.properties`
- Use log levels: TRACE, DEBUG, INFO, WARN, and ERROR
- Write application logs to a file
- Customize logging configuration using `logback-spring.xml`
- Configure package-specific logging levels

## Getting Started

1. Clone the repository.
2. Open the project in your preferred IDE.
3. Run the Spring Boot application.
4. Check the console output and `logs/spring.log` for application logs.

This project is part of my hands-on learning journey with Spring Boot, focusing on application logging and configuration.
